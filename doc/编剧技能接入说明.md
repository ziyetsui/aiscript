# 编剧技能接入说明

本次接入保留已有快捷指令、工作流名称与快捷键，新增专业细分入口。共 **49 个快捷指令、74 个方法资源**。专业编剧 System Prompt 单独交付在 [专业编剧-System-Prompt.md](./专业编剧-System-Prompt.md)，供系统提示词配置使用；本次应用接入仍使用原有写入协议，并按任务注入技能方法。

## 使用与路由

在聊天输入框的「+ → 快捷指令」中搜索名称、关键词或分类，选择后输入框显示技能标签。可以编辑起始提示词，所选技能仍随请求发送；清除标签则恢复按用户指令识别技能。首页创建项目和工作区消息队列均保存所选技能。

显式选择优先；未选择时仅根据用户指令匹配，最多两个入口、三个方法。项目剧本文本、知识库与导入素材不会触发路由。方法上下文按完整章节截取，总预算约 18,000 字符，保留来源与截取提示。长技能并非每次全文发送。

技能中的脚本、外部工具、文件布局和媒体生成命令作为方法参考，不自动执行。当前应用的操作协议、用户要求、项目事实与规则优先。改稿继续经过预览、接受与撤销流程。

## 能力边界与验证

这些入口提供真实方法上下文，而非只更换菜单文案；创作质量仍取决于模型、素材和项目约束。参考经典案例只提取结构与技法，不复制原作的具体剧情、人物及标志性表达。

分镜、资产、视频和剪辑入口输出规划、文本或提示词。没有新增图像／视频生成引擎、上游 Python 校验脚本执行器或素材制作平台。转录继续使用现有服务；无需新增 OpenAI Key。「今日热点选题」沿用主分支的 NewsNow 官方 MCP 热点简报，再由编剧方法辅助选题；缺少真实联网结果时不声称已查询。

验证覆盖方法注入、标题路由、来源边界、无效标识与上下文预算，以及真实 Electron 界面中的搜索、首页创建、修改起始提示词、排队消息技能隔离、改稿预览、接受和撤销。桌面端到端测试使用本地模拟 Ancher 响应验证请求与编辑行为，不代表真实模型创作质量评测。
