# Ancher Scripter 安装与激活

此目录为 1.0.0-beta.1 候选版本。使用前请阅读 build-manifest.json 的平台验收状态。

1. Apple 芯片 Mac 选择 mac-arm64.dmg；Intel Mac 选择 mac-x64.dmg；Windows 10/11 64 位选择 win-x64-setup.exe。
2. Mac 打开 dmg，将 Ancher Scripter 拖入「应用程序」。Windows 运行安装器，选择目录和快捷方式。
3. 打开后复制激活页的机器码，发给提供者。每台电脑有不同机器码，需要分别签发激活码。
4. 将收到的 AIS1- 激活码粘贴到「手动激活」。本地编辑不需要联网，首次 AI 使用需要填写自己的 Ancher API key。
5. 设置 → 模型与密钥 → 填入 Ancher key 并验证。Gemini key 可选，主要用于视频转写。
6. 从首页新建项目；已有 .scripter 文件可「导入项目」。导出整个项目可迁移到另一台电脑；另一台电脑仍须单独激活。

没有 Developer ID 公证或 Windows 签名的候选包可能被系统拦截。先核对文件来源与 SHA256；仅在系统提供允许打开/运行的选项时按该系统正常流程操作。不要关闭系统防护，不运行终端绕过安全检查的命令。若系统不给允许选项，请联系提供者取得签名版本。

## 保存与更新

项目保存在本机用户应用数据目录；密钥使用系统加密存储。请定期「导出 → 整个项目」备份。项目移入回收站后可恢复；彻底删除无法恢复。

此 beta 使用手动更新：关闭应用，使用提供者发来的新版安装包覆盖安装。不删除应用数据目录。升级前先导出项目备份。

## 已知限制

- 生成画面提示词可复制使用；当前版本不生成图片或视频。
- 快速视频专属流程、语音输入、多人协作和云同步未开放。
- 联网搜索、媒体解析、视频转写依赖用户服务商账户/网络；mock E2E 不代表服务商真实能力已验证。
- Windows / Intel Mac 实机验收是否通过，以 build-manifest.json 和交付验收报告为准。

遇到问题，在设置里导出诊断包提供给开发者；不要把 API key 或私钥放进截图/邮件。
