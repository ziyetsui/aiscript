# 发行者操作

源码仓库：ziyeprompttheworld/aiscript。现有签发密钥保持不变。

公钥在 apps/desktop/resources/license-public.pem；私钥只保存在 ~/.ancher-scripter/license/private.pem（0600）。不要将私钥发给客户、提交仓库或放进安装包。安全备份现有私钥后再分发，不重新生成密钥。

客户安装后发来机器码，使用：

```sh
pnpm license issue --machine AS-XXXX-XXXX-XXXX-XXXX --customer 客户名称 --seat 1/3
```

输出的 AIS1- 码只发给对应客户。另两台分别签发 2/3 和 3/3。客户名/席位和实际授权核对后再签发；本次尚未收到客户机器码，不预制通用授权。

打包：pnpm --filter @scripter/desktop dist:mac / dist:win。
收集：pnpm deliver。缺任何必需 dmg/zip/exe 会失败，避免误发不完整目录。

候选包需要三个目标平台验收，再记录验收结果和接收人/渠道。未配置正式签名时不声称签名/公证通过。
