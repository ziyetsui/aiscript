# Ancher Scripter 新用户安装指南

这份指南帮助你在一台新电脑上完成安装、激活和首次使用。请使用发行者交付的安装包；无需编程经验，也无需在终端安装开发依赖。

## 一、安装前准备

你需要准备：

1. 一台 Mac 或 Windows x64 电脑。
2. 发行者提供的 Ancher Scripter 安装包。
3. 能访问 Ancher 的网络；视频转写还需要访问所选 Google 服务。
4. 自己的 Ancher 账号和 API key。
5. 如果需要转写本地视频或音频，再准备 Gemini API key。暂时不使用转写功能可以先跳过。

安装完成后，应用会显示本机机器码。把机器码发给发行者，领取这台电脑专用的激活码。

### 需要额外安装 Node.js、Python 或其他依赖吗？

**使用正式交付的安装包，不需要自己安装这些开发依赖。** 运行组件已经包含在客户端中：

| 组件 | 作用 | 客户需要自己安装吗？ |
| --- | --- | --- |
| Electron | 运行桌面应用 | 不需要 |
| Ancher SDK | 连接 Ancher AI 服务 | 不需要，只需填写自己的 API key |
| Mastra | 组织生成、校验和写入步骤 | 不需要 |
| FFmpeg | 处理音视频、提取音轨 | 不需要 |
| yt-dlp、Deno | 获取 YouTube 视频信息、字幕或音轨 | 不需要 |
| 文档存储组件 | 保存剧本、笔记和项目 | 不需要安装数据库 |

如果你拿到的是源码文件而非安装包，请让发行者提供与你的电脑匹配的安装包。需要自行从源码启动时，另见[从零安装依赖与运行客户端](从零安装依赖与运行客户端.md)。

## 二、选择适合电脑的安装包

| 电脑类型 | 安装包文件名中的标识 |
| --- | --- |
| Apple 芯片 Mac，例如 M1、M2、M3、M4 | `mac-arm64.dmg` |
| Intel 芯片 Mac | `mac-x64.dmg` |
| Windows x64 电脑 | `win-x64-setup.exe` |

Mac：点击左上角苹果菜单 →「关于本机」，查看「芯片」或「处理器」。

Windows：打开「设置 → 系统 → 系统信息」，查看系统类型是否为 x64。Windows ARM 和 Linux 不属于当前安装包交付目标，请先联系发行者确认。

只从发行者提供的渠道获取安装包；文件版本、系统兼容性和验收状态以本次交付说明为准。

## 三、Mac 安装步骤

1. 下载匹配的 `.dmg` 文件。
2. 双击打开下载的文件。
3. 将 **Ancher Scripter** 图标拖到「应用程序 / Applications」文件夹。
4. 等待复制完成。
5. 在访达侧边栏弹出安装磁盘镜像。
6. 打开「应用程序」，双击 **Ancher Scripter**。

以后从「应用程序」启动，不需要每次重新打开 `.dmg`。

如果系统提示无法验证开发者或阻止打开，请先向发行者核对来源，再按 macOS 正常提供的允许打开流程处理。没有允许选项时，请联系发行者提供签名、公证版本。

## 四、Windows 安装步骤

1. 下载匹配的 `win-x64-setup.exe` 文件。
2. 双击运行安装程序。
3. 按向导选择安装目录，确认是否创建快捷方式。
4. 点击安装，等待完成。
5. 从桌面快捷方式或开始菜单启动 **Ancher Scripter**。

如果系统提示未知发布者或拦截程序，先向发行者核对来源和签名，再按系统正常提示处理。没有允许选项时，联系发行者提供签名版本。

## 五、激活客户端

首次打开会显示激活页面。

1. 找到以 `AS-` 开头的机器码。
2. 复制完整机器码，发送给发行者。
3. 收到以 `AIS1-` 开头的激活码后，粘贴到「手动激活」。
4. 点击激活，等待进入应用。

每台电脑的机器码不同。换电脑时，需要新电脑对应的激活码；不能直接使用另一台电脑的码。

如果提示「激活码属于另一台电脑」「已过期」或「校验失败」，先检查是否完整复制，再把错误信息和本机机器码发给发行者核对。

## 六、连接 Ancher AI

客户端激活后，还需要填写 Ancher API key 才能使用 AI。

1. 在浏览器打开 [Ancher 官网](https://ancher.ai)，登录自己的账号。
2. 按官网当前的账号/API 设置获取自己的 API key；找不到入口时请联系 Ancher 或发行者协助。
3. 确认账号已完成服务要求的激活，并有可用额度。
4. 回到客户端，打开「设置 → 模型与密钥」。
5. 在 Ancher key 输入框粘贴密钥。
6. 点击「验证并保存」。
7. 看到连接成功提示后，返回首页。

**客户端激活码和 API key 不能混用。** 激活码用于开通这台电脑上的客户端；Ancher key 用于连接 AI 服务，AI 用量按照你的服务账户结算。

密钥在本机经系统加密后保存。不要把它放进剧本、公开截图或共享文档。

## 七、第一次创建和编辑项目

1. 从首页新建项目，填写故事需求或项目名称，按页面提示开始。
2. 在写作页选择「剧本」，可以手动输入内容。
3. 输入一两行文字，等待自动保存。
4. 返回首页后，通过「最近项目」重新打开，确认文字还在。
5. 在右侧 AI 对话框输入一个小请求，例如：

   > 为这个故事写一场简短开场，直接写入剧本。

6. 检查生成结果是否显示在剧本里。涉及修改已有内容时，查看修改预览，再选择接受或拒绝。

需要一起更新大纲时，可以发送：

> 修改当前剧本，并同步更新本集大纲，使大纲与剧本一致。请实际写入两个文档。

人手输入文字时会自动播放打字机音效；AI 写入不会播放。可以在设置中调整音量。

## 八、使用知识库和笔记

进入「知识库」，顶部可以选择两个来源：

| 入口 | 可以看到什么 |
| --- | --- |
| Ancher 笔记 | 当前 Ancher key 所属账号在官网保存的笔记、合集等内容 |
| 项目笔记 | 当前项目中的本地文件、逐字稿、字幕和保存的 AI 回复 |

找不到预期笔记时，先检查打开的是不是正确项目，再检查选择的笔记来源。

- 查看官网新保存的内容：进入「Ancher 笔记」并刷新。
- 把官网笔记留在当前项目：打开笔记后点击「保存到项目」。
- 让 AI 阅读某条笔记：点击「添加到对话」，然后输入问题并发送。
- 把项目笔记长期用于写作：打开相应笔记并启用「写作时参考」。

本地项目笔记可离线查看和编辑；读取官网笔记需要网络和对应账号的 Ancher key。

## 九、需要视频转写时，再配置 Gemini

如果暂时只写剧本，不必配置 Gemini。

### 9.1 准备密钥

选择一种服务：

- **Google AI Studio**：获取对应的 Gemini API key。
- **Google Cloud**：使用支持当前 API-key 请求方式的项目和 key；需确认 Google 服务权限与配额已经配置。

Google Cloud 服务账号 JSON、OAuth access token 不能直接粘贴到客户端的 API key 栏。

### 9.2 在客户端保存

1. 打开「设置 → 模型与密钥」。
2. 选择与密钥相对应的 Gemini 服务。
3. 粘贴 Gemini key。
4. 点击验证并保存。
5. 使用一个较短、声音清晰的视频先测试。

### 9.3 执行转写

1. 打开项目和 AI 对话里的快捷指令/工作流菜单。
2. 选择「视频 → 逐字稿」。
3. 选择本地视频或音频，按提示执行。
4. 等待完成，避免处理中退出客户端。
5. 在「知识库 → 项目笔记」查看 TXT 逐字稿和 SRT 字幕。

转写后会尝试通过 Ancher 生成笔记标题和摘要。如果该步骤失败，已经完成的逐字稿和字幕仍会保留，可以手动修改标题。生成内容、字幕时间和人名建议人工检查。

处理音视频不需要另装 FFmpeg。转写会把音视频或提取的音频发送给所选 Google 服务，并使用你的服务账户额度。

### 9.4 YouTube 视频

使用菜单中的 YouTube 转写流程，并粘贴实际视频网址。有可用字幕时会优先读取字幕；没有可用字幕时，需要 Gemini 处理下载的音轨。

如果 YouTube 要求验证登录，按客户端提示选择已经登录的浏览器并允许读取登录信息；或者改用有权使用的本地视频。网址可在浏览器打开，不代表下载工具一定拥有访问权限。

## 十、保存、备份与换电脑

应用会自动保存当前项目。建议完成重要修改后：

1. 点击「导出」。
2. 选择导出整个项目，保存为 `.scripter` 文件。
3. 把备份文件复制到另一处保存。

Word、PDF 等格式方便阅读；迁移或恢复项目请使用整个项目的 `.scripter` 备份。

换电脑后安装匹配的客户端，单独激活新电脑，重新填写自己的 API key，再导入 `.scripter` 项目。API key 和客户端授权不能用项目备份代替。

## 十一、更新客户端

当前 beta 以发行者提供的新安装包手动更新。

1. 先导出重要项目备份。
2. 保存工作，等待正在执行的 AI 请求或转写结束。
3. 完全退出客户端。
4. 使用新版安装包覆盖安装。
5. 重新打开，检查项目、剧本和项目笔记是否正常。

不需要为了更新而删除应用数据文件夹，也不需要重新安装 Node.js 等开发工具。

## 十二、常见问题

| 问题 | 先做什么 |
| --- | --- |
| 程序打不开 | 检查安装包是否匹配系统/芯片，将系统提示发给发行者 |
| 卡在激活页 | 核对本机机器码和收到的激活码是否对应 |
| AI 没有回复 | 检查网络、Ancher key 验证状态、账号激活与额度 |
| 官网有笔记，客户端找不到 | 检查 Ancher key 是否对应同一个账号，选择「Ancher 笔记」并刷新 |
| 找不到本地逐字稿 | 打开生成它的项目，选择「项目笔记」 |
| Gemini 403 | 核对服务类型、key 与 Google 权限配置 |
| Gemini 429 | 核对额度、配额或限流，稍后再试 |
| 没有打字声音 | 检查系统音量、静音、输出设备和应用音量设置 |
| 更新后仍显示旧内容 | 退出所有应用窗口，确认从应用程序/开始菜单启动已更新的客户端 |

仍无法解决时，请提供系统版本、芯片类型、客户端版本、操作步骤和错误截图；也可在设置中导出诊断包。发送前检查内容，不包含 API key 或不希望共享的资料。

## 十三、安装完成检查

- [ ] 客户端可以打开并已激活。
- [ ] Ancher key 验证成功。
- [ ] 能新建项目，手动输入并重新打开文字。
- [ ] AI 可以生成一个简短场景。
- [ ] 知识库里能选择「Ancher 笔记」和「项目笔记」。
- [ ] 已导出一份整个项目备份。
- [ ] 如需视频转写，Gemini 已验证，短视频转写成功。

完成这些步骤后，就可以正常使用客户端了。
