# Bundled fonts

Courier Prime Regular/Bold: Google Fonts `ofl/courierprime`, downloaded 2026-10-09 from https://github.com/google/fonts/tree/main/ofl/courierprime. License: CourierPrime-OFL.txt (SIL Open Font License 1.1).

朱雀仿宋 Zhuque Fangsong Regular: TrionesType v0.212, https://github.com/TrionesType/zhuque/releases/tag/v0.212. License: Zhuque-OFL.txt (SIL Open Font License 1.1).

Fonts are embedded in the desktop renderer and PDF export. Word export records font names; Word must have matching fonts installed to use them. Original font binaries have not been modified.
